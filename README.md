# 商店价格本（ShopPriceApp）

给自家商店用的商品价格管理小工具。无数据库、无联网，数据（含商品照片）只存在手机本地文件夹，两台手机之间通过蓝牙互相传输同步。

## 功能

- 录入商品：名称、成本价（自己进货价）、售价（卖给顾客价）、数量
- **商品拍照**：编辑页点图片区域可拍照或从相册选择，自动压缩保存到 App 专用文件夹（photos 目录）
- **查找**：主页顶部搜索框输入名称即可实时过滤商品
- 增删改查：点右下角 + 添加；列表带图片缩略图，点某条记录进入编辑页修改；长按删除
- 蓝牙同步：两台手机都装本 App，一次传输后两边商品数据和图片完全一致（只传对方缺少的图片，速度快）
- 冲突处理：同一条商品两边都改过时，自动保留"最近修改"的那份

## 怎么拿到 APK（GitHub 云端自动打包）

不需要在自己的电脑上安装任何安卓开发环境，全部在 GitHub 云端完成：

### 第一步：注册 GitHub 账号

打开 https://github.com 注册一个免费账号（记住用户名和密码）。

### 第二步：新建仓库并上传本项目

1. 登录后打开 https://github.com/new
2. Repository name 填 `ShopPriceApp`，选择 **Public**（公开仓库打包免费），点 **Create repository**
3. 在新页面找到 **"uploading an existing file"** 链接点进去
4. 把本文件夹（ShopPriceApp）里的**所有文件和子文件夹**拖进上传区
   - 注意：必须包含隐藏文件夹 `.github`（Windows 资源管理器里需要先在"查看"里勾选"隐藏的项目"才能看到它）
   - 直接把整个文件夹拖进去也可以（推荐用 Chrome/Edge 浏览器）
5. 等文件上传完，页面底部点 **Commit changes** 确认提交

### 第三步：等待云端自动编译

1. 打开仓库页面的 **Actions** 标签页
2. 会看到 "Build APK" 任务正在运行，大约 5~10 分钟
3. 变成绿色对勾 ✔ 后，点进该任务，翻到页面底部 **Artifacts** 区域
4. 点 **ShopPrice-APK** 下载，解压得到 `app-release.apk`

### 第四步：安装到手机

1. 把 `app-release.apk` 通过微信/数据线/网盘传到手机
2. 在手机上点开 apk，提示"未知来源"时选择允许安装即可

## 怎么使用蓝牙同步

前提：两台手机都装了本 App，并且**先在系统蓝牙里互相配对**（第一次需要配对，之后就不用了）。

1. 两台手机都打开"商店价格本"
2. 点右上角 **蓝牙同步**
3. 一台手机点 **① 本机做接收端（等待对方连接）**
4. 另一台手机点 **② 本机做发送端（发送给对方）**，在弹出的列表里选对方手机
5. 两边都显示"同步完成"即可

同步后两台手机的商品数据完全相同。之后任何一台添加/修改/删除商品，再蓝牙同步一次即可。

## 注意事项

- 数据保存在手机 App 自己的文件夹里（`shop_data.json`），**卸载 App 会丢失数据**，请勿轻易卸载；换新手机前先用蓝牙同步到新手机。
- 两台手机距离需在 10 米以内。
- 同步时一台是"接收端"、一台是"发送端"，两边不能同时点同一个按钮。
- App 更新新版本后直接安装即可覆盖（签名已固定，不用卸载）。
- `keystore/shop.p12` 是打包签名文件，**请保留在项目里不要删除**，否则以后打包的版本无法覆盖安装。
